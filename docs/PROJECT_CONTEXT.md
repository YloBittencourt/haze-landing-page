## 📌 Visão Geral
O projeto **HAZE Oficial** foi idealizado para ser o canal primário de conversão digital do rapper HAZE. O objetivo central é substituir o uso de agregadores de links genéricos (como Linktree) por uma infraestrutura proprietária, de alta performance e visualmente sofisticada, garantindo total controle sobre os dados de tráfego e a jornada do usuário.

## 🎯 Objetivos de Negócio
1. **Centralização de Audiência:** Criar um ambiente único para concentrar o tráfego vindo de redes sociais (Instagram/TikTok).
2. **Conversão de Streams (B2C):** Facilitar a audição das faixas (Singles/EPs) diretamente na página, removendo atritos para aumentar os *plays* no Spotify.
3. **B2B Booking (Contratantes):** Servir como uma vitrine de credibilidade premium para produtores de eventos, com CTAs diretos para fechamento de shows via WhatsApp e E-mail.

## 👥 Público-Alvo
* **Fãs / Ouvintes (Mobile-First):** Usuários que buscam consumo rápido de conteúdo, clipes e músicas.
* **Produtores / Mídia:** Profissionais em busca de *press kit* (informações de base, gênero e tempo de atividade) e canais oficiais de negociação.

## 🧠 Estratégia de CRO (Otimização de Conversão)
* **Single Page Layout:** Navegação linear ininterrupta para evitar fuga do usuário.
* **Fricção Zero:** Uso de iframes compactos do Spotify integrados na própria página (Tracklists interativos).
* **Tracking Inteligente:** Botões com rastreamento (GA4) para qualificação de leads e futuras campanhas de tráfego pago (Remarketing).
